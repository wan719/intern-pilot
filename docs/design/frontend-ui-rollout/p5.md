## 浏览器验收

Windows，Edge 157.0.4341.60，1440×960 和 375×812，使用合成账户及拦截的 HTTP API。分析准备、恢复任务的 68% 进度、报告和题单概览、键盘展开参考答案均通过。桌面和移动均无页面横向溢出。每个视口对比打印页直接打开与同一个 SPA 会话从面试页导航过去。两种打开方式均输出两页 PDF，逐页栅格相同，列表圆点保留且打印工具条隐藏。

预览端口为 15205，使用 `npm run preview -- --host 127.0.0.1 --port 15205 --strictPort`。在同一目录运行 `node scripts/check-analysis-p5.cjs`，需要本机 Edge、Playwright Core、Poppler 的 `pdfinfo` 和 `pdftoppm`。可通过环境变量 `INTERNPILOT_PLAYWRIGHT` 指定 Playwright Core 安装路径。结果、截图和打印对照保存在本地 `frontend/dist/ui-p5-evidence/`。

真后端写操作、真实 WebSocket 传输、外部 AI 服务和生产验收留待独立验证。任务恢复使用模拟 HTTP 数据。
