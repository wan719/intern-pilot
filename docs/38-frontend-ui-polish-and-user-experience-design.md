# InternPilot 前端界面优化与用户体验增强设计文档

## 一、文档目的

本文档用于指导 InternPilot 项目进行前端界面优化、交互体验增强和答辩展示观感提升。

当前项目已经具备较完整的业务功能，包括：

1. 邮箱注册登录
2. JWT 鉴权
3. RBAC 权限系统
4. 简历管理
5. 岗位 JD 管理
6. AI 简历匹配分析
7. WebSocket 分析进度
8. AI 面试题生成
9. RAG 知识库
10. 用户中心
11. 管理员后台
12. Docker 在线部署

当前阶段目标不是继续堆功能，而是让系统更像一个完整产品，提高老师、同学、面试官访问在线系统时的第一印象。

---

## 二、本阶段目标

本阶段目标：

> 优化 InternPilot 前端页面视觉一致性、交互反馈、空状态、加载状态、错误提示、移动端适配和答辩展示效果，使系统从“功能可用”提升到“观感完整、体验顺畅、适合演示”。

---

## 三、本阶段不做什么

本阶段暂不做：

1. 不新增大型后端功能
2. 不重构后端业务逻辑
3. 不修改数据库结构
4. 不修改 RBAC 权限规则
5. 不接入新的 UI 框架
6. 不大规模替换 Element Plus
7. 不做复杂动画系统
8. 不做移动端 App
9. 不影响现有接口
10. 不修改线上 DeepSeek 配置

本阶段只做：

```text
前端页面美化
组件统一
交互反馈增强
空状态优化
错误提示优化
答辩展示观感优化
````

## 八、交互规范

### 8.1 Loading

所有异步操作必须有 loading：

1. 登录
    
2. 注册
    
3. 发送验证码
    
4. 上传简历
    
5. 创建岗位
    
6. 发起 AI 分析
    
7. 生成面试题
    
8. 删除
    
9. 修改密码
    
10. 保存资料
    

---

### 8.2 Empty

所有列表必须有 empty：

1. 简历列表
    
2. 岗位列表
    
3. 分析报告列表
    
4. 面试题列表
    
5. 投递记录列表
    
6. RAG 知识库
    
7. 操作日志
    

---

### 8.3 Error

错误提示要能让用户理解。

不推荐：

```text
Request failed
unknown error
500
```

推荐：

```text
登录失败，请检查邮箱或密码
验证码已过期，请重新获取
AI 分析失败，请稍后重试
没有权限访问该页面
```

---

### 8.4 Confirm

危险操作必须确认：

1. 删除简历
    
2. 删除岗位
    
3. 删除分析报告
    
4. 删除面试题
    
5. 删除用户
    
6. 删除角色
    
7. 删除 RAG 知识
    
8. 修改用户角色
    
9. 修改角色权限
