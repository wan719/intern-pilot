# InternPilot v1.4.0 — Product UI Redesign

Tag: `v1.4.0` · Commit: `e278add294b8c4b06e719d6567a12a17900ad88e`
Tag 创建日期：2026-08-26；发布说明整理日期：2026-10-08（Asia/Shanghai）。

## 本次更新

InternPilot 以五阶段求职旅程重新组织导航和工作台，统一简历、岗位、AI 分析、面试准备和投递管理的页面布局，保留既有业务功能与接口契约。

- 重设计登录、注册、用户工作台、用户中心和核心业务页面，提供移动底部导航及明确的加载、空数据、错误与重试状态。
- 管理后台采用独立分组导航和统一表格、筛选、表单组件；按权限过滤入口，并加固权限撤销后的操作边界。
- 改善 AI 长任务恢复、面试生成与再生成的跨页面状态；修复默认简历初始化、详情请求竞态和关闭抽屉后的迟到响应。
- 引入 Vitest 与 Vue 组件测试，覆盖导航契约、业务操作、权限边界、请求顺序和失败恢复。
- 相较 v1.3.1，还包含后端测试增强、JaCoCo 报告产物、HTTPS 部署配置、CORS、Actuator 反向代理与上传相关修复。

[完整版本差异](https://github.com/wan719/intern-pilot/compare/v1.3.1...v1.4.0)：55 个提交、145 个文件。此处描述的是整个 Tag 区间，范围大于单次 UI 重塑。

## English summary

This release redesigns the job-search journey, workspace, mobile navigation and admin experience while preserving existing workflows and API contracts. It improves asynchronous task recovery, permission changes and stale-response handling, and adds front-end component tests.

Local verification on 2026-10-08 passed 296 front-end tests across 36 files, the typed production build, and 296 back-end tests across 55 suites. The v1.3.1-to-v1.4.0 interval also includes back-end coverage improvements and HTTPS / proxy fixes. Docker build, production availability, live AI/email checks, native print preview and updated screenshots were not verified in this local validation.
